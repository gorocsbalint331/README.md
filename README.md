## About

I am a senior engineer at [Qyvarex](https://qyvarex.com), where I build custom software around real workflows, integrations, and growth. My work sits across five practices that usually get split across teams:

- **Full stack** — interfaces, APIs, data layers, and the glue between them
- **AI** — applied models, retrieval, and production ML systems
- **Blockchain** — smart contracts, Web3 integrations, and on-chain security
- **DevOps** — infrastructure as code, Kubernetes, GitOps, and reliable delivery
- **Cybersecurity** — application security, cloud security, and defensive engineering

I care about systems that stay understandable in production: clear boundaries, observable behavior, and security designed in from the start.
